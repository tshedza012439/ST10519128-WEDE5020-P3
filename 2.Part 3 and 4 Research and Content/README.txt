# 1. Project Overview

Tshipidi Bakery is a fictional bakery website that I created as part of my Web Development project. The purpose of the website is to provide customers with information about the bakery, display bakery products, promote custom celebration cakes, and provide customers with an easy way to make enquiries and contact the bakery.

The website was developed in two main parts.

**Part 1** focused on research, planning, content creation, website structure, sitemap development and the creation of the basic HTML pages.

**Part 2** improved the website by adding an external CSS stylesheet, typography, layouts, visual styling, pseudo-classes and responsive design. Additional functionality, including a product shopping cart, was also added using JavaScript.
